# Лабораторная 4 — Статистический анализатор (версия под наше железо)

**Вариант 1.** Приложение для базового статистического анализа табличных данных. Обработка организована в виде конвейера на основе архитектуры **«Каналы и фильтры»**.

## 1. Оборудование и среда

Лабораторная подготовлена под ту же конфигурацию, которую мы используем для остальных работ:

- **Процессор:** Intel Core i7-12650H, 2,30 ГГц;
- **Оперативная память:** 16 ГБ;
- **Операционная система:** Windows 10;
- **JDK:** 17;
- **JavaFX:** 21.0.6;
- **Maven**;
- **Apache POI** — работа с Excel;
- **Apache PDFBox** — экспорт PDF;
- **JUnit 5** — тестирование.

В исходной версии был указан Java 21. Для общей среды проекта версия компиляции изменена на **Java 17**. В коде заменены только конструкции, требующие Java 21 (`getFirst()`/`getLast()`), на эквивалентные обращения по индексу. Остальная логика лабораторной сохранена.

---

# 2. Что делает программа

Это настольное JavaFX-приложение, которое берёт таблицу Excel и выполняет базовый статистический анализ выбранных числовых столбцов.

Пользователь может:

1. открыть существующий файл `.xlsx` или `.xls`;
2. либо создать демонстрационный Excel-файл;
3. выбрать лист;
4. выбрать один или несколько столбцов;
5. указать диапазон строк;
6. выбрать способ обработки пустых и нечисловых ячеек;
7. выбрать делитель для стандартного отклонения — `n` или `n−1`;
8. нажать **«Рассчитать»**;
9. получить статистику по каждому выбранному столбцу;
10. увидеть **box plot / ящик с усами**;
11. увидеть сообщения о пропущенных или некорректных значениях;
12. экспортировать график или таблицу.

---

# 3. Что происходит после запуска

Запуск начинается с класса:

```text
Launcher
   ↓
App
   ↓
создание JavaFX-интерфейса
   ↓
выбор Excel-файла
   ↓
формирование AnalysisData.Request
   ↓
AnalysisPipeline
```

Главная идея программы — данные проходят через несколько независимых этапов.

```text
Excel-файл
    ↓
ExcelLoadFilter
    ↓
ParseFilter
    ↓
PrepareFilter
    ↓
StatisticsFilter
    ↓
VisualizationFilter
    ↓
Report
    ↓
┌───────────────┬────────────────┐
│ JavaFX экран  │ Экспорт файлов │
└───────────────┴────────────────┘
```

Каждый этап получает результат предыдущего этапа и передаёт результат следующему.

---

# 4. Архитектура «Каналы и фильтры»

В лабораторной используется архитектурный принцип **Pipes and Filters — «Каналы и фильтры»**.

Основной интерфейс:

```text
Filter<I,O>
```

означает, что фильтр получает объект одного типа `I` и возвращает объект типа `O`.

Соединение выполняется через:

```text
Pipeline<I,O>.then(...)
```

Получается конвейер:

```text
Request
  ↓
ExcelLoadFilter
  ↓
Raw
  ↓
ParseFilter
  ↓
Column
  ↓
PrepareFilter
  ↓
Column
  ↓
StatisticsFilter
  ↓
Analyzed
  ↓
VisualizationFilter
  ↓
Report
```

Преимущество такого подхода — каждый этап выполняет свою отдельную задачу и не знает внутреннее устройство остальных этапов.

---

# 5. Загрузка Excel

Первым работает:

```text
ExcelLoadFilter
```

Он использует **Apache POI**.

Файл может быть:

```text
.xlsx
.xls
```

Фильтр:

1. открывает книгу;
2. получает лист;
3. читает заголовки;
4. читает значения ячеек;
5. обрабатывает формулы через `FormulaEvaluator`;
6. формирует промежуточное представление таблицы.

Числовые ячейки читаются без округления отображаемым форматом.

---

# 6. Разбор значений

Следующий этап:

```text
ParseFilter
```

Он преобразует содержимое Excel в числовые значения.

Поддерживаются текстовые числа с:

- десятичной точкой;
- десятичной запятой;
- пробелами между разрядами.

Например:

```text
"123.45"
"123,45"
"1 234,50"
```

могут быть распознаны как числа.

Не считаются измерениями:

- даты;
- логические значения;
- ошибки формул;
- бесконечные значения;
- неподдерживаемый текст.

Если выбран режим пропуска, программа продолжает расчёт и формирует предупреждения.

---

# 7. Подготовка данных

Работает:

```text
PrepareFilter
```

Он проверяет объём данных и подготавливает значения к статистическому анализу.

Для расчёта квантилей значения сортируются.

Каждый выбранный столбец анализируется **независимо**.

---

# 8. Статистические расчёты

Основная вычислительная часть находится в:

```text
Statistics
StatisticsFilter
```

Рассчитываются:

| Показатель | Что означает |
|---|---|
| Среднее | сумма значений / количество |
| Стандартное отклонение | мера разброса данных |
| Q1 | первый квартиль |
| Q2 | медиана |
| Q3 | третий квартиль |
| IQR | Q3 − Q1 |
| Нижний ус | минимальное значение, не являющееся выбросом |
| Верхний ус | максимальное значение, не являющееся выбросом |
| Выбросы | значения за границами `1,5·IQR` |

Среднее рассчитывается алгоритмом **Уэлфорда**.

Для квантилей используется линейная интерполяция, тип 7:

```text
позиция = (n − 1) · p
```

где `p` может быть:

```text
0,25
0,50
0,75
```

---

# 9. Определение выбросов

Границы:

```text
нижняя = Q1 − 1,5 · IQR
верхняя = Q3 + 1,5 · IQR
```

Выбросом считается:

```text
x < нижняя
```

или:

```text
x > верхняя
```

Значения, которые точно лежат на границе, выбросами не считаются.

Например, в демонстрационном столбце:

```text
10, 11, 12, 12, 13, 14, 15, 15, 16, 17, 18, 45
```

программа получает:

```text
среднее = 16,5
медиана = 14,5
Q1 = 12
Q3 = 16,25
IQR = 4,25
```

Значение `45` определяется как выброс.

---

# 10. Делитель стандартного отклонения

Пользователь может выбрать:

```text
n
```

или:

```text
n − 1
```

При `n` используется деление на количество наблюдений.

При `n−1` получается стандартная выборочная оценка дисперсии.

Особый случай:

```text
n = 1
```

допустим только при использовании делителя `n`; отклонение тогда равно нулю.

При режиме `n−1` требуется минимум два значения.

# 11. Построение ящика с усами

После расчётов работает:

```text
VisualizationFilter
```

Он не рисует график непосредственно в JavaFX.

Вместо этого создаётся единая модель:

```text
PlotDocument
```

Она содержит геометрию:

- линий;
- прямоугольников;
- точек;
- текста.

Для box plot используются:

```text
Q1 ─────── Q3
│          │
└─ медиана ┘
```

Усы показывают крайние допустимые наблюдения.

Выбросы отображаются отдельными точками.

---

# 12. Почему используется PlotDocument

Это важная часть архитектуры.

Одна и та же геометрия используется:

```text
PlotDocument
     │
     ├── JavaFX
     ├── PNG
     ├── SVG
     ├── PDF
     └── HTML
```

Поэтому расчёт положения элементов графика не дублируется в каждом формате.

`ChartView` отвечает за отображение на экране.

`ChartExporter` отвечает за экспорт графика.

# 15. Работа в фоновом потоке

Чтение Excel, расчёты и экспорт не должны блокировать JavaFX-интерфейс.

Поэтому тяжёлые операции выполняются в фоновом потоке.

Получается:

```text
JavaFX UI
    │
    ├── пользователь продолжает видеть интерфейс
    │
    ▼
фоновая задача
    │
    ├── чтение Excel
    ├── расчёты
    └── экспорт
```

Это позволяет интерфейсу не зависать во время обработки большого файла.

# 18. Что сказать преподавателю

> В лабораторной работе разработан статистический анализатор табличных данных. Программа работает с Excel-файлами и позволяет выбрать лист, столбцы и диапазон строк. После этого данные проходят через конвейер, реализованный по архитектуре «Каналы и фильтры».
>
> Сначала `ExcelLoadFilter` загружает таблицу через Apache POI. Затем `ParseFilter` преобразует значения в числовые данные, `PrepareFilter` проверяет и сортирует их, а `StatisticsFilter` рассчитывает основные статистические показатели.
>
> После расчётов `VisualizationFilter` создаёт единую геометрию box plot. Эта геометрия используется как JavaFX-интерфейсом, так и экспортёрами PNG, SVG, PDF и HTML.
>
> Программа рассчитывает среднее, стандартное отклонение, квартили, медиану, IQR, усы и выбросы. Для квантилей используется линейная интерполяция. Выбросы определяются по правилу 1,5 IQR.
>
> Архитектура позволяет разделить загрузку, обработку, статистический анализ и визуализацию на независимые этапы. Благодаря этому каждый фильтр можно тестировать отдельно и при необходимости заменить без переписывания всей программы.
